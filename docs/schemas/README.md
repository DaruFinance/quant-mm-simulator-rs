# Schemas

Single source of truth for the trade-log row shape lives upstream in [`quant-research-framework`](https://github.com/DaruFinance/quant-research-framework/blob/v2-main/docs/schemas/trade_log_v1.json). This engine emits rows that conform to that schema; nothing here overrides it.

Aux-log streams get their own schemas under this directory when added.
